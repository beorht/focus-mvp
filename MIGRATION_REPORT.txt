🚀 БЫСТРЫЙ СТАРТ (5 минут)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Установить PostgreSQL:
   $ sudo apt install postgresql   # Linux
   $ brew install postgresql       # macOS

2. Создать БД:
   $ sudo -u postgres createdb focus_mvp

3. Применить миграции:
   $ npm install
   $ npx prisma migrate deploy

4. Проверить:
   $ npx prisma studio
   # Откроется http://localhost:5555

5. Запустить приложение:
   $ npm run dev

Вопрос: Что делать если БД не создается?
Ответ:  Убедитесь что PostgreSQL запущен:
        $ sudo systemctl start postgresql

Вопрос: Как изменить пароль PostgreSQL?
Ответ:  $ sudo -u postgres psql
        postgres=# ALTER USER postgres WITH PASSWORD '1234';

Вопрос: Как посмотреть все таблицы?
Ответ:  $ npx prisma studio
        или
        $ psql -U postgres -d focus_mvp -c "\dt"

Вопрос: Как откатить все миграции?
Ответ:  Удалить БД и создать заново:
        $ sudo -u postgres dropdb focus_mvp
        $ sudo -u postgres createdb focus_mvp
        $ npx prisma migrate deploy
